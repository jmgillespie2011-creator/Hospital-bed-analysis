Data & sources

Every number the model uses is listed here with where it came from. All inputs are built from published NHS England, NHS England Digital and ONS files by the scripts in the GitHub repository (scripts/fetch_raw_data.py downloads the raw files, scripts/build_inputs.py processes them, scripts/calibrate.mjs calibrates the model). The raw files and a manifest with checksums are kept in data/raw/. Data file generated: .

You can also download the complete input file the simulator loads: baseline.json.

Headline inputs

Calibrated values

Quantities that cannot be observed directly, each tuned so the model reproduces one measured figure for the baseline year (see Methods).

Bed numbers over time

Before 2010/11 NHS England's KH03 return counted beds by ward type, annually. From 2010/11 it counts beds by consultant specialty, quarterly, which reduced reported beds by around 10%. Earlier years are therefore also shown on a consistent definition (see notes).

Age bands

Public health settings

How each public health setting is linked to hospital admissions (see Methods).

Delayed discharges

Delay after the Discharge Ready Date for patients discharged later than it (NHS England, average of the baseline year's months), and the gamma distribution fitted to it.
